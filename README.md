DataInsight-AI provides an integrated environment for uploading datasets, performing automated EDA, creating interactive visualizations, asking questions in natural language, discovering analytical insights, and generating reports. By combining conventional data-processing techniques with AI-assisted analysis, the application helps users move from raw data to understandable findings more efficiently.
## Features
- Automated EDA
- Interactive visualizations
- Natural-language data analysis
- AI-assisted insights
- Report generation
